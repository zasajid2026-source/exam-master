# Exam Master — Landing Page

Urdu (RTL) landing page for the Exam Master Android app: full introduction with real
app screenshots, intro video, annual price (Rs 16,000/year) and EasyPaisa payment
instructions with a WhatsApp screenshot button.

## Publish on GitHub Pages

1. Create a new GitHub repository (e.g. `exam-master`).
2. Upload ALL files from this folder, keeping the structure:
   - `index.html`
   - `intro-video.mp4`
   - `assets/` (all images)
3. In the repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   choose branch `main` and folder `/ (root)`, then **Save**.
4. After a minute the page is live at `https://<username>.github.io/<repo>/` —
   put this link in the video ad description.

All paths in `index.html` are relative, so the page also works from a subfolder.
No build step is needed.
